# [Software Carpentry Lessons](https://software-carpentry.org/lessons/)

Software Carpentry is a free learning service which is taught by a trained and badged instructor. There are six lessons in English and three lessons in Spanish

[The Software Carpentry website is linked here.](https://software-carpentry.org/lessons/)

### Software Carpentry Lessons

The six lessons in English will cover these topics:

1. [The Unix Shell](https://swcarpentry.github.io/shell-novice/)
- This will teach you the basics of Linux commands and Command-Line commands to use within your computers built in terminal.
2. [Version Control with Git](https://swcarpentry.github.io/git-novice/)
- Version control with Git and GitHub is an excellent way to document your coding work, saving your coding work, and view past work.
3. [Programming with Python](https://swcarpentry.github.io/python-novice-inflammation)
- Python is a common coding language for data science, automation, and scripting - so learning Python will be very useful when it comes to data analysis.
4. [Plotting and programming with Python](https://swcarpentry.github.io/python-novice-gapminder)
- This is an introductory for people with very little experience in Python.
5. [Programming with R](https://swcarpentry.github.io/r-novice-inflammation/)
- R, similar to Python, is a coding language that is often used for data analysis.
6. [R for Reproducible Scientific Analysis](https://swcarpentry.github.io/r-novice-gapminder) 
- This is a more in-depth introductory to R.

The three lessons in Spanish will cover these topics:

1. [La Terminal de Unix](https://swcarpentry.github.io/shell-novice-es)
2. [Control de versiones con Git](https://swcarpentry.github.io/git-novice-es)
3. [R para Análisis Científicos Reproducibles](https://swcarpentry.github.io/r-novice-gapminder-es)

### Additional Lessons

These supplmentary lessons are not necessary to learn, but if the topics interest you, or if you would like to keep learning about coding, these are always helpful.

1. [Automation and Make](https://swcarpentry.github.io/make-novice)
- Make is a tool which can run commands to read files, process these files in some way, and write out the processed files.
2. [Programming with MATLAB](https://swcarpentry.github.io/matlab-novice-inflammation) 
- This lesson will not teach you how to use MATLAB, but to teach you the basic concepts that all programming depends on.
3. [Using Databases and SQL](https://swcarpentry.github.io/sql-novice-survey)
- This lesson will teach you how to aggregate and collate a database with SQL.
